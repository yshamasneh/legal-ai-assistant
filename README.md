# ⚖️ Legal AI Assistant

> AI-powered legal consultation platform for Palestinian law

A full-stack web application that provides instant legal consultations using OpenAI's GPT-4 combined with a custom RAG (Retrieval-Augmented Generation) pipeline.

## 🚧 Status

Currently in active development. Backend & Frontend infrastructure complete. AI integration in progress.

## 🛠️ Tech Stack

**Frontend:**
- React 18 + Vite
- Tailwind CSS
- Three.js (for 3D scenes)
- Axios

**Backend:**
- Node.js + Express 5
- MongoDB Atlas + Mongoose
- JWT Authentication
- bcrypt

**AI/ML:**
- OpenAI GPT-4 SDK
- Python RAG Pipeline (in progress)
